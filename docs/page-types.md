# Page Types

Each page should have one learning goal.

## problem_scene

Creates motivation through a concrete problem before naming the concept.

## intuition_visual

Builds intuition through analogy, concrete example, or visual metaphor.

## structure_diagram

Reveals internal structure such as trees, flows, state machines, tables, or architecture maps.

## process_animation

Shows meaningful state change over time.

## interactive_model

Lets the learner manipulate a model and observe cause and effect.

## code_walkthrough

Connects intuition to implementation with short, purposeful code.

## quiz

Checks understanding through a question that tests mental model quality.

## misconception_check

Surfaces a common wrong belief and gives corrective feedback.

## transfer_challenge

Asks the learner to apply the same idea in a new but related context.

## summary_card

Compresses the lesson into durable recall cues.
