# Learning Principles

> 历史说明：这些原则仍可作为长期学习产品理念，但不能覆盖当前默认形态。当前默认生成以 `docs/current-product-spec.zh-CN.md` 为准：学生自学型学术 Web Deck，内容密度和来源论证优先，互动和测验为可选能力。

## Product Thesis

The system should help learners build correct, durable, transferable mental models. It should not optimize for turning source material into pages.

## Core Sequence

Prefer this teaching order:

```text
real problem
  -> intuitive situation
  -> visual model
  -> learner action
  -> explanatory feedback
  -> formal terminology
  -> code or formula
  -> transfer task
```

## Design Rules

- Start from a concrete problem, not a definition.
- Use visuals to expose hidden structure, state, process, and causality.
- Use interaction only when the learner must think or make a decision.
- Every interaction must produce explanatory feedback.
- Introduce formal terms after intuition.
- End with a transfer task in a related but new context.

## Feedback Standard

Feedback should explain:

- What assumption the learner may have made
- Why that assumption works or fails
- Which mechanism produced the result
- How to update the learner's mental model

Avoid feedback that only says "correct", "incorrect", or "try again".
