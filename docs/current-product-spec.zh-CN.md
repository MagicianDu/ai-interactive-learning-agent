# 当前产品权威 Spec：学生自学型学术 Web Deck

状态：当前默认生产规范。  
更新时间：2026-05-19。  
适用范围：Codex、Claude 或类似 agent 通过 MCP / skills 把书籍、论文、专利、博客和技术资料生成中文学习产品。

## 1. 权威层级

后续生成、评审和修订必须按以下优先级解释项目文档：

1. 本文件：当前产品定义与默认生成规则。
2. `AGENTS.md` 顶部的“当前权威目标”。
3. `docs/runtime/*` 中明确标注为当前生产流程的文档。
4. `docs/archive/*` 和早期 MVP / 互动课程 / teacher mode 文档：仅作历史背景，不得作为默认生成目标。

如果旧文档要求 quiz、misconception check、transfer challenge、teacher mode、课堂活动或互动组件，但本文件没有要求，则旧要求降级为可选能力。

## 2. 当前默认产品形态

默认产品不是 PPT、教师课件、互动测验课、博客摘要或 artifact 控制台。

默认产品是：

```text
学生自学型学术 Web Deck
```

目标用户是想快速读懂复杂资料的学习者，尤其是大学高年级、本科高阶、研究生或研究论文精读场景。用户不想先读完整本书或整篇资料，而是希望通过一组浏览器页面掌握核心问题、概念链路、证据边界和迁移限制。

## 3. 页面合同

每页必须像一页紧凑的自学教材，而不是给老师讲课用的提示卡。

默认页面结构：

1. 标题：一个具体知识命题或真实学习问题。
2. 中间区域：图片 + 学术讲解正文。图片由 Codex 内容设计后交给 imagegen 生成，正文解释本页命题。
3. 底部一句话：可复习、可带走的压缩判断。

页面中可以保留 `knowledgeBoard` 等结构化字段作为内部渲染和审核数据，但不得把这些字段变成可见模板栏目。

禁止默认出现：

- 本讲定位、课堂讨论、教授讲义、课后作业、教学目标、教学设计。
- 判断入口、推理链路、证据边界、自检问题这类固定栏目。
- “学习者需要看见问题、机制和边界”等 rubric 话术。
- “对研究论文学习来说，关键不是……”这类内部质量标准复述。
- 每页重复同一套标题、headline、coreProposition、左右栏和 bottomLine。

## 4. 内容质量标准

每页至少交付一个来源驱动的学术判断。

合格页面应包含其中多数要素：

- 明确命题：这页到底要让学生理解什么。
- 概念区分：相近概念、术语或机制不要混在一起。
- 机制链路：解释为什么成立，而不是只说结论。
- 来源依据：说明来自哪类来源主张、证据、例子或限制。
- 适用边界：指出在哪些条件下不成立或不能外推。
- 学术浓度：使用资料中的关键术语、问题设定、方法结构和证据边界。

不合格页面的典型坏味道：

- 只说学习策略，不讲知识本身。
- 把质量要求写给学生看。
- 用通用模板替代来源里的具体问题。
- 只有“概念很重要”“需要理解”这类空句。
- 图片、标题、正文、底部总结彼此重复。

## 5. 图像规则

默认中间区域只消费图片资产，不渲染表格或程序化伪图示。

图片流程：

1. Codex 先判断本页最适合画什么知识关系。
2. imagegen 生成教学插图。
3. 页面渲染消费图片。
4. 质量门禁检查图片存在、不是 SVG、prompt 不允许长段文字、表格、UI 面板或重复正文。

图片可以有短标签和方向提示，但不能重复页面标题、底部总结或正文卡片。

## 6. 入口与交互边界

默认入口是 Codex、Claude 或类似 agent 的自然语言交互。MCP 负责准备来源、发布、记录状态和质量检查，不负责替代大模型完成高质量写作。

学习者不审批中间 artifacts。默认流程应该是：

1. 通过几轮自然语言明确资料、难度、页数、组织方式。
2. Codex / Claude 设计并创作内容。
3. MCP 发布和校验。
4. 用户直接打开 Web Deck 学习。

quiz、interaction、teacher mode、playground、canvas、AI tutor 都是后续可选产品面，不是当前默认内容生成目标。

## 7. 课程打包策略

默认不要机械追求“完整覆盖整本书 / 整篇论文 / 全部章节 / 全部 topic”。

更合理的默认策略是：

1. 先生成一个总览单元。
2. 再补 3 到 5 个最能代表资料核心价值的 focused topic 单元。
3. 当学习者已经能够通过这些单元建立稳定心智模型时，可以先停止，不必为了形式完整继续扩写。

优先停在“小而完整”的课程包，而不是“页数很多但边际价值快速下降”的大课程包。

适合停在小课程包的信号：

- 总览课已经把研究问题、方法机制、证据范围和迁移边界讲清楚。
- 3 到 5 个核心 topic 已覆盖最关键的结构、分工、边界或案例。
- 后续 topic 主要是在重复相同判断框架，而不是引入新的高价值认知动作。
- 继续扩写的主要动机只剩“把它做完整”，而不是显著提升学习价值。

只有在以下情况才建议继续扩展：

- 资料本身具有明显章节推进关系，后续章节引入新理论层次。
- 学习者明确要求更完整覆盖。
- 后续 topic 会显著改变对前面内容的理解，而不是只做同构重复。

## 8. 质量门禁

即使结构分数达到 90+，只要出现以下问题，仍应判为不可发布：

- 教师课件味重，不像学生自学教材。
- 学术密度不足，不能支撑大学高年级 / 研究生学习。
- rubric 或 reviewer 语言漏出。
- 模板栏目伪装成内容。
- 每页图片、标题、正文、底部总结重复。
- source grounding 只挂锚点，不说明具体支撑关系。

质量通过的定义是：学习者阅读后有明确知识获得感，而不是只看到一套完整课程流程。
